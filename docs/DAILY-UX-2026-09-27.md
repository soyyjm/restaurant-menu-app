# Menú del Día 易用性改进

状态：本地实现与验证完成，未提交、未发布，未写入正式数据库。

## 改动

- **价格与节假日可配置**：平日价、周末/节假日价、节假日列表、营业时间、餐厅名、电话、地址统一放在「Ajustes → Restaurante, precios y horario」，保存在现有 `settings.print_settings` JSON 中，可跨设备同步。默认节假日补到 2027 年，并加入巴塞罗那本地节日 Segunda Pascua 与 La Mercè。电话和地址原来只存在本机，首次加载时会迁入同步设置。
- **价格逻辑合并**：去掉 ⭐ 特价按钮。价格框里的价格就是这一天的价格，已按日期自动保存。与默认规则不同时标注「Precio personalizado」，并显示「↺ Precio por defecto」按钮。旧 `specialPrices` 数据仍然会读取。
- **预览即 PDF**：预览区直接渲染 PDF 模板，按比例缩放显示，可切换 Color / B&N。「Imprimir / PDF」和「Compartir」使用同一页面。旧的简易打印版式、未使用的 `generatePDF()` 以及 10 项像素级样式设置已删除，改为标题、西语菜名、加泰语译名三个百分比。旧设置键仍然保留，可以正常读取。
- **导出前检查**：预览上方实时列出以下问题：缺少某个分类、缺少加泰语译名、缺少价格、日期已过、所在年份未配置节假日。导出或分享时如果有问题，会先弹出确认。
- **手机底部操作栏**：宽度在 900px 以下时，底部固定显示「Vista previa / PDF / Compartir」。
- **布局**：日期与价格 → 7 天日期条 → 添加菜品（常用菜并入同一卡片）→ 当前菜单（标题显示日期，「Copiar de」放在标题旁）→ 批量录入 → 菜库 → 历史。
- **添加按钮合并**：只保留「Añadir al menú」一个按钮，旁边加「Guardar también en la biblioteca」勾选框（默认勾选，本机记住）。「Solo biblioteca」和 Shift+Enter 只存入菜库。
- **撤销**：从菜单移除菜品、清空菜单、删除菜库菜品后，提示条里都带「Deshacer」按钮。删除菜库菜品不再弹确认框，撤销后会取消尚未完成的云端删除；如果已经删除，会重新写回。
- **避免重复**：自动补全、菜库和菜单卡片会显示「servido hace N días」或最后一次上菜日期，数据来自已加载的历史。历史里可以按菜名搜索。
- **菜库**：可以直接编辑西语名、加泰语名和分类，并可按全部、收藏或分类筛选。
- **分享**：设备支持时，直接分享与预览相同的 PDF 文件；否则分享文字。甜点改为西语一行、加泰语一行。

## 注意

- 2027 年节假日为默认推算值，需要对照加泰罗尼亚和巴塞罗那的官方日历核实。可以在「Ajustes」里直接修改。
- 修改默认价格只影响还没有保存价格的日期。

## 补充：打印样式与菜库重复

- **恢复「Sencillo」样式并设为默认**：这是以前的纯黑白文字排版，只有页眉下和营业时间上方各一条细线，内容从页面顶部开始排。字号沿用原来的像素设置，再乘以「Diseño」里的百分比。预览上方可以在 Sencillo / Color / B&N 之间切换，选择保存在同步设置 `pdfStyle` 中，所有设备一致。
- **黑白 PDF 体积**：给 PNG 加上 `FAST` 压缩后，单页从约 31 MB 降到约 120 KB，画质无损。Color 版仍使用 JPEG。
- **重复原因**：同一台设备上本来就会拦截重复。但每台设备只在打开页面时读取菜库，两台设备各自添加同一道菜时，都会上传一份新的，云端就出现两条完全相同的记录。
- **预防**：保存菜库前先读取云端列表并合并，如果云端已经有同一道菜（忽略大小写和多余空格），就丢弃本机新增的那一份。页面重新回到前台时也会刷新菜库。
- **合并工具**：菜库标题会显示「N repetidos」。点「Revisar y fusionar」后，按分类列出看起来相同的菜品，判断时忽略大小写、空格、重音和末尾句点。
  - 默认保留收藏过的那条，没有收藏时保留最早创建的一条。也可以手动改选。
  - 其余的会被删除；如果被删的那条是收藏，星标转到保留的那条。菜单和历史不受影响。
  - 可以单组合并，也可以全部合并，合并后可以撤销。
- 测试：76 项全部通过。浏览器中验证了 Sencillo 预览和 PDF、样式同步、合并与撤销、两台设备添加同一道菜时不再产生重复，以及 390px 宽度下的布局。

## 补充：三个排版模板的调整

- **自动适配页面**：三个模板共用 `fitText`，通过 `--pt-fit` 按比例调整字号和间距。菜少时把字放大，填满页面的一部分：Color/B&N 最多放大到 1.35 倍，Sencillo 最多 1.5 倍。菜多时，只有真的放不下才缩小，最小 0.7 倍；仍然放不下时，再整体缩放。
- **Color / B&N**：
  - 以前的做法是把剩余高度平均加到每道菜后面，菜少时菜品之间空得很大，分类标题也离菜品很远。现在剩余空间先加到分类之间（每处最多 40px），再加到菜品之间（每处最多 16px），还剩的空间让整块内容整体居中，位置略偏上。
  - 菜品改为居中，与标题和分类标题的对齐方式一致。
  - 甜点改为用「·」分隔的一行，字号接近其他菜品。
  - 价格下面的双线改为单线，分类标题从 10px 调大到 11.5px。
  - 日期加上星期，放在左边，价格放在右边。
- **Sencillo**：保持原来的样子（黑白、左对齐、两条细线），只把日期改为带星期，并让短菜单的字适当放大。
- 验证：分别用 6 道、12 道、17 道菜，渲染三种模板共 9 张页面并逐一检查。测试 76 项全部通过，浏览器回归检查没有报错。
- 后续调整：Sencillo 改为居中。三个模板中的甜点都固定排成一行，放不下时只缩小这一行的字号，不换行。

## 补充：线上检查后的修正

用 Claude in Chrome 打开线上网站（menusol.netlify.app）只读检查，没有改动任何数据。检查时菜库共 544 道菜，已经没有同名同分类的重复；发现以下问题并做了修正：

- **重复检测范围扩大**：比较菜名时，忽略末尾的加价，例如「(+3.50€)」「(+ 2,00 €)」，也忽略括号前后的空格。另外新增一类「同名但在不同分类」的提示，例如一道菜同时在 Segundo 和 Postres。
  - 这一类不会自动勾选保留哪一条，「Fusionar todos los repetidos」也不会处理它们，必须由你选择正确的分类。
  - 每组都可以点「No son repetidos」忽略。忽略记录保存在同步设置中；如果这组又出现新的相似菜品，会重新提示。
- **甜点字号**：新增「Postres, respecto a los platos (%)」，默认 90%，三个模板都使用这个比例。Sencillo 以前沿用旧设置里的 13px（普通菜名 18px），现在按普通菜名的 90% 计算，并且仍然保持一行。
- **页面顶部排版**：日期和价格一栏改为单独占一行。宽度约 1100px 时，标题不再被挤成三行，价格标签也不会被预览区挡住。
- 测试：78 项全部通过。在 1100px 宽度下用接近真实的菜单（18 道菜、7 种甜点）验证了预览和重复检查面板，之前的浏览器回归检查也没有报错。

## 补充：菜品排序

- 去掉了菜品右侧只在鼠标悬停时才出现的 ▲▼ 按钮，改为先选中再移动：点一下菜品即选中（左侧显示橙色竖条，背景高亮），然后用该分类标题右侧固定的四个按钮移动：移到最前、上移、下移、移到最后。按钮旁显示当前位置，例如「3 de 5」。
- 移动后菜品保持选中，可以连续点击调整。再点一次同一道菜取消选择。选中别的分类的菜时，这个分类的按钮不可用，避免移错。分类里只有一道菜时不显示这组按钮。
- 键盘操作：Tab 移到菜品上，按 Enter 或空格选中；Alt+↑ / Alt+↓ 移动一格，同时按住 Shift 移到最前或最后；Esc 取消选择。
- 仍然可以拖拽排序。编辑和删除按钮保留在每道菜的右侧。
- 手机上按钮放大到 44×40px，单独排成一行，页面不会横向溢出。
- 测试 79 项全部通过（新增排序测试）。在浏览器中验证了桌面、键盘、拖拽和 390px 手机宽度，之前的回归检查也没有报错。

## 补充：菜品排序（Menús Cerrados）

- Menús Cerrados 以前无法调整菜品顺序，新加的菜只能排在最后。现在每个分组的顶部右侧都有同样的四个排序按钮：移到最前、上移、下移、移到最后。
- 点进某道菜的任意输入框，这道菜就被选中（行高亮，左侧出现橙色竖条），然后用这组按钮移动。移动后光标仍留在这道菜上，可以连续调整。Alt+↑ / Alt+↓ 移动一格，同时按住 Shift 移到最前或最后。
- 其他语言版本的菜名按菜品 ID 对应，不按位置，所以调整顺序后译文不会错位（已验证 Sopa → Sopa catalana、Pescado → Peix）。
- 新顺序和其他修改一样，先保存为本地草稿，点「Guardar」后才会保存到云端。
- 分组本身的上移、下移仍然在「⋯」菜单里。

## 补充：联想列表的键盘操作

- 用 ↑ / ↓ 移动时，列表会自动滚动，让高亮的一项始终可见；PageUp / PageDown 每次跳 5 项，Enter 选中。
- 列表最高 320px（不超过屏幕高度的 45%），以前是 200px，带译名的长菜名只能看到两条左右。最多显示 20 条匹配（以前 8 条），以输入内容开头的菜排在前面。
- 同时修复了一个问题：选中联想项或自动翻译后，如果再修改西语名，加泰语框里仍保留旧译名，添加后会存成错误的译名。现在自动填入的译名会在西语名改动时清空；自己手动输入的加泰语不受影响。
- 线上检查后补充：窗口约 1100px 宽时，西语输入框只有约 180px，联想列表和输入框一样宽，长菜名要折成四到六行，一次只能看到两条左右。现在列表可以比输入框宽，最宽 520px，且不超出屏幕。1100px 宽时一次能完整看到 6 条；手机上宽度不超出屏幕，没有横向滚动。
- 联想列表精简：每条只显示西语名。只有输入内容匹配的是加泰语名时，才同时显示加泰语，否则看不出这道菜为什么被搜出来。分类标签缩短为「1º / 2º / Postre」，上菜提示缩短为「hace N d」放在右侧；完整信息（加泰语名、分类、上次上菜时间）放在鼠标悬停提示里。1100px 宽时一次能完整看到 8 条（以前 5 条）。选中后加泰语仍会自动填入右侧的输入框。
