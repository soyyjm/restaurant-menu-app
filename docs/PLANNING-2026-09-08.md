# 提前准备多日菜单

录入区提供 Hoy（今天）、Mañana（明天）、Pasado mañana（后天），以及任意日期选择器。快捷日期以马德里今天为基准。页面持续显示正在准备的日期。

切换日期前保存原日期菜单，再打开目标日期；原日期本地保存失败时不切换。仅打开目标日期不创建空历史记录。价格按目标日期已有价格或日期规则显示。

重新打开或刷新页面默认打开今天，未来菜单仍按原日期保留。此规则不在页面持续打开期间自动跳转，避免打断正在编辑的未来菜单；需要回到今天时点击 Hoy。

验证：49 项自动测试通过；模拟 SDK 浏览器验证后天录入、往返切换保留、刷新回到今天；320px 手机截图检查通过。未写正式数据库。发布方式为推送 main 触发现有 Netlify 流程，托管完成状态需另行确认。
