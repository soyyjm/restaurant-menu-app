# 长期历史管理

本地实现，尚未发布。云端历史不会因本轮修改被删除。

- 历史区可按月份查询云端，默认显示已加载的最近 60 条；日期选择及复制快捷操作在缺少本地记录时查询云端，查询失败不按空菜单覆盖。
- 每次启动单独读取今天的菜单，避免大量未来日期把今天挤出最近 60 条。
- 持久化快照只保留最近 90 个已加载日期的菜品内容，另保留当前日期、所有待同步日期及尚未确认有云端副本的日期。未同步数据可能超过 90 条，优先避免丢失。当前页面已加载内容暂留内存；价格元数据仍保留。
- 设置页区分本地备份与全部云端历史导出。云端历史按日期游标每页 500 条完整读取；失败不输出部分历史。导出另包含当前菜单与待同步日期，菜库和收藏来自当前设备已加载数据，不是整库快照。
- 完整历史导出继续使用现有 JSON 格式及 5 MB / 5,000 日期限制，超过限制会失败，不会截断为部分文件。大量历史的分卷备份仍属后续工作。
- 导入前核对全量云端日期，避免因本地缓存缺失而误覆盖旧记录。离线未登录导入仍只能依据本地数据判断；跨设备并发修改不提供数据库快照隔离。

验证：53 项自动测试通过。模拟浏览器中查询 2020 年 2 月返回 29 条；导出 520 条云端历史及当前菜单共 521 个日期，跨越分页边界。未访问正式 Supabase 数据。
