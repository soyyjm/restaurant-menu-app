# 每日菜单备份与恢复

状态：本地完成，未发布；测试使用合成数据，没有访问正式数据库。

## 使用方法

1. 打开设置 `⚙️`，在 `Copia del menú diario` 点击 `Descargar copia`，保存 JSON 文件。
2. 恢复时点击 `Abrir copia…`，选择同类备份，先查看新增与保留数量。
3. 点击 `Añadir datos faltantes y sincronizar` 并确认后，补入缺失数据；登录状态下沿用现有同步机制，失败可重试。

文件包含菜库、收藏、每日菜单历史及对应价格，也包含当前打开的每日菜单。仅导出明确列出的业务字段，不导出数据库身份、登录状态、密码或翻译密钥。

不包含套餐（Menús Cerrados）、打印设置、餐馆联系方式或尚未加入菜单的批量输入。此功能是每日菜单数据备份，不是整个系统的数据库备份。

## 恢复规则

- 同分类、同西班牙文名称的菜库条目保留现有内容；忽略大小写和多余空格。只给新增菜品恢复备份中的收藏状态。
- 已有历史日期和当前打开日期不覆盖。若要找回当前日期，先切换到另一日期，再打开备份；导入后可在历史中恢复原日期及价格。已存在历史的日期不会被本功能替换。
- 菜品使用新 ID，防止与本地现有记录冲突；重复导入同一文件不重复新增。
- 确认时重新检查最新数据，切换账号后原预览失效。一次选择多个文件时只保留最后选择的结果。
- 本地存储失败时整体撤回本次导入，不发送云端写入。云端保存失败时保留本地待同步状态。
- 文件最大 5 MB，最多 10,000 条菜库记录、5,000 个菜单日期、每日期每分类 500 条。拒绝未知版本、非法日期、重复日期和损坏的菜品结构。
