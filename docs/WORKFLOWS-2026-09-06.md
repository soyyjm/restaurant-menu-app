# Menu 第二轮使用流程优化

状态：本地实现与回归验证完成，未发布，未写入正式数据库。

## 完成内容

- 套餐双语按同一系列、同一版本的稳定菜品 ID 对应，调整顺序或存在空行时不会错配。旧数据没有共同 ID 时，可用 `Revisar correspondencias de idiomas` 明确选择对应项。原文或译文改变后，旧对应失效并提示复核。
- 选中的打印语言缺少对应译文时阻止导出，避免输出错配菜单；可补齐对应或仅选择原文语言。
- 套餐编辑按账号保存在本机，切换套餐、刷新后可恢复。`Guardar` 明确保存到云端，失败保留草稿；保存期间继续编辑不会丢失后续内容。可放弃本地草稿恢复已保存版本。
- 套餐保存检查原服务器更新时间，检测到并发修改时保留草稿，避免直接覆盖。响应丢失时仅在重新读取的内容完全一致后确认成功。
- 菜库星标收藏与常用菜快捷添加。常用排序参考最近 30 个历史菜单日期，每菜每天只计一次；已选菜不可重复添加。
- 批量录入支持每行一道菜，格式为 `西班牙文 | 加泰罗尼亚文`，也支持制表符。每批最多 50 行，自动去重、复用菜库译文；可编辑、取消选择、选择分类及是否存入菜库。
- 批量翻译支持停止和失败重试，保留已完成内容，只重试缺失译文。所选行译文不全时不会部分加入菜单。批量输入与准备中的条目可在本机恢复。

仅面向餐馆管理层，未增加员工角色或复杂权限层级。
