# 团餐（Menú cerrado / Menú para grupos）：链接选菜 + 后厨汇总（2026-11-16）

## 页面
| 页面 | 地址 | 谁用 |
|---|---|---|
| 团餐管理 | `https://menusol.netlify.app/grupos.html` | 员工（用菜单系统的同一个账号登录） |
| 组织者页面 | `/m/<码>` | 订台的组织者（例如 Ana） |
| 个人选菜页面 | `/e/<码>` | 组织者转发给同事、朋友，每人自己选 |
| 演示版 | `grupos.html?demo` | 带一个 24 人的示例（Menú Degustación），数据只存在本机浏览器 |

## 流程
1. **员工新建团餐**：选一个已有的 **Menú cerrado**（菜单系统里编辑好的），填写日期、时间、名称、组织者、电话 / Email、人数。
   选菜截止日默认是用餐前 2 天。系统会保存一份菜单快照，以后修改 Menú cerrado 不会影响已经发出的团餐；需要更新时，点“同步菜单”。
2. **发给组织者**：通过 WhatsApp、Email 或复制消息，内容是西班牙语，附上组织者链接。
3. **组织者在自己的页面选择一种方式**，两种方式可以混用：
   - **每人自己选**：把个人链接发到群里。每人填写名字，每个 “A elegir uno” 分区选一道菜，可以写过敏信息。
     同一部手机可以再帮别人选（伴侣、孩子），也能回来修改或删除。提交后立即计入统计。
   - **组织者统计**：发送菜单图片或 PDF（样式和打印的 Menú cerrado 一样，列出过敏原和补差价），然后在页面上按数量填写“没有名字的人”。
   - 组织者可以看到所有人的选择，可以添加、修改、删除任何人，页面显示 “Han elegido X de 24”（已有 X / 24 人选好）。
4. **后台**：显示进度、后厨汇总（每道菜的份数，以及补差价合计）、过敏和备注、按人明细（名字、头道、主菜、来源）。员工也可以代录或修改。
5. **出菜单**：打印两页西班牙语出菜单。COCINA 页有汇总和 MARCHAR 勾选框；SALA 页还有按人表格，按名字上菜，没有名字的人另外列出数量，最后是补差价合计。

## 规则
- 只有 Menú cerrado 里模式为 **“A elegir uno”** 的分区需要客人选择；“Para compartir”（共享）和固定的分区只展示，不用选。
- 人数上限：已选的人数加上组织者填的数量，不能超过订台人数。满员后，个人链接会显示 “El grupo ya está completo”（人已经满了）。
- 截止日之后、用餐当天，或者员工点了“截止选菜”，两个链接都只能查看，不能再修改。
- 个人链接看不到电话、Email、组织者链接，也看不到别人的选择。组织者链接能看到全组的选择。

## 上线
1. 在 Supabase 的 SQL Editor 里运行 `supabase/006_grupos.sql`（需要先运行过 004 和 005）。
   这个文件同时加固了 005 的 `fiesta_orders` 权限：订单只能挂在自己的订台下。
2. 推送到 GitHub，Netlify 会自动部署（`netlify.toml` 里已经加了 `/m/*`、`/e/*` 的跳转规则）。
3. 本地模拟测试：`supabase/006_simulation.mjs`，38 项全部通过。
