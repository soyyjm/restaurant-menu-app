## 3. 申请阶段必须具备的文件

### A. 官方申请表及附件

- [ ] 电子申请表：在官方程序中在线填写并电子签名；
- [ ] `Memoria de la actividad`：填写主体、地址、活动、设备、替换理由、节能逻辑、预算和状态；
- [ ] AEAT 最新 `Certificado de situación censal`；
- [ ] 最新官方 CNAE 证明；
- [ ] 申请主体的代表/授权资料（如电子程序要求）；
- [ ] `Declaración Responsable I y II`：按申请人真实情况勾选、填写、签署；
- [ ] 代表提交时的 `Contrato de otorgamiento de representación`；本人直接提交时通常不使用此附件；
- [ ] 最终供应商报价：必须足够详细，列出设备型号、数量、净额、IVA、含税总额、安装/调试/运输等分项；
- [ ] 如把独立技术能耗报告费用列入预算：同时附上该报告的报价/预报价；
- [ ] 如官方程序要求的其他声明或权限文件。

### B. 设备和技术证据

- [x] 旧烤箱完整型号、额定功率、电源和可识别铭牌：`MSUPERIORE UMI`、5.6 kW、380–415 V 3PH + N + PE、序列号 `20250512002`；
- [ ] 旧烤箱整体照片及其确实在餐馆使用的现场照片；
- [ ] 新 RATIONAL 烤箱的官方技术资料、型号和额定功率；
- [ ] 底座及 UltraVent（如列入）与烤箱兼容的书面资料；
- [ ] 水电工程师/电工书面说明：现有烤箱支路的 20 A 保护装置、10.8 kW 新烤箱线路、63 A/380 V 总配置和厨房其他同时使用设备之间的安全性；
- [ ] 电工同时确认 RATIONAL 安装手册要求的保护方式；官方手册对 6-1/1 E（3 AC 400 V）列出 10.8 kW、15.6 A、16 A 保险/保护值，并列出 RCD 类型要求。设备支路满足厂家参数，不等于餐馆总容量和同时负荷已经自动满足；
- [ ] 供应商或安装方书面说明：现有进水、排水和电源可否直接使用，实际需要哪些接驳、固定和调试；
- [ ] UltraVent 是否为无外接风管的循环/冷凝方案、冷凝水如何排放、是否需要排水接驳，以及当地通风、卫生、消防规则是否允许；
- [ ] 如新设备没有欧盟能源标签：由独立于供应商和安装方的合资格工业技术工程师出具节能比较报告，或至少取得其正式报价并确认报告范围。

## 4. 获批后才需要补齐的证据

这些材料不应在申请阶段伪造或提前声明已经存在：

- [ ] 新设备正式发票；
- [ ] 银行付款证明，付款主体与申请主体一致；
- [ ] 安装完成证明、调试记录和最终技术说明；
- [ ] 旧烤箱由授权废弃物管理方接收、拆除或处理的证明；
- [ ] 只有在正式申报大型燃气铁板也被替换且实际拆除时，才需要增加该铁板的授权回收证明；若保留作工作台，不提交其废弃证明，也不宣称已经正式废弃；
- [ ] 最终节能技术报告（如纳入申请或官方要求）；
- [ ] 现场完成前后照片；
- [ ] 最终证明/`justificación` 和其他官方要求文件。

## 5. 当前不能提交的原因

以下任一项未完成，都不把文件称为最终申请：

1. 供应商尚未提供与“RATIONAL 功能性替代旧烤箱和大燃气铁板烹饪功能”一致的最终分项报价；
2. 电工结论目前只有口头信息，没有书面确认同时负荷、线路截面、保护/RCD 配置和当地安装规范；
3. UltraVent 的必要性、排水方式和当地合规性尚未书面确认；
4. 旧烤箱的整机运行状态、门封/保温情况和预计使用年限仍未整理；这些资料用于节能说明和现场证据，不影响铭牌型号与功率的已确认状态；
5. 申请主体、AEAT 地址、CNAE、代表关系和 `de minimis` 事实尚未填入；
6. Memoria、责任声明和最终预算仍有待确认字段；
7. 尚未完成提交前的官方版本复核和电子签名上传。
