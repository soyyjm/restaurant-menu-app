## 当前工作方案

申请以一项设备更新为核心：

- 替换餐馆现有旧工业烤箱；
- 购买 RATIONAL iCombi Pro 6-1/1 E，参考号 `CB1ERRA.0000817`；
- 配套 RATIONAL 底座 `60.31.046`；
- 核实并酌情购买 RATIONAL `UltraVent Plus` 冷凝排风罩（6-1/1 参考号拟为 `60.75.142`）；
- 新烤箱位置据现场工程师反馈已有电源、进水和排水；只计入实际必要的接驳、固定和调试，并必须取得分项报价；
- 旧的大型燃气铁板停止烹饪使用；RATIONAL 在功能上承担其主要烹饪任务，若旧铁板保留在原位则只作为工作台，不拆除、不列入申请预算；
- 不申请电热铁板、新燃气铁板或冷冻柜。

电热铁板方案不进入当前预算和活动说明。旧燃气铁板的可能型号 `MAINHO FC-1807` 仅为无铭牌的内部线索，不作为最终技术证据。若日后要把旧燃气铁板作为正式被替换设备申报，必须先实际拆除并取得授权回收证明；保留作工作台时只写功能性替代。

## 当前关键缺口

### 必须由餐馆/申请人确认

- 申请主体的法律形式和名称，以最新 AEAT `Certificado de situación censal` 为准；
- 最新官方 CNAE 证明；
- 经营场所正式地址和邮编。当前网页资料写 `C/ Clot 123-127, Bajos, 08026 Barcelona`，报价单写 `c/ del Clot 123`，存在差异；
- 旧烤箱清晰铭牌已确认型号 `MSUPERIORE UMI`、序列号 `20250512002`、功率 `5.6 kW` 和三相 `380–415 V`；仍需补充整机照片和使用状态资料；
- 电子证书/签名方式和可接收通知的联系方式；
- `de minimis` 援助情况及责任声明所需事实。

### 必须由供应商/专业人员确认

- 修订后的供应商报价：净额、IVA、含税总额、准确型号、底座和安装工作分项；
- 原报价 2,500 € 排水及人工费用必须取消或按新现场实际工作重报，不能直接沿用；
- UltraVent Plus的准确型号、安装方式、冷凝水排放、是否无需外接风管及当地规范适配性；
- 电工对 63A/380V 配置、烤箱 10.8 kW 线路和其他同时负荷的结论；
- 旧新烤箱的节能技术比较报告；
- 旧烤箱授权回收和废弃物证明的取得方式；
- 新旧设备的节能比较报告，不能只比较铭牌功率。

## 正式提交闸门

在以下项目全部完成前，不把任何草稿称为最终申请：

- [ ] 旧烤箱型号、能源和功率已由正确铭牌确认；
- [ ] 电工以书面形式确认 10.8 kW 烤箱及配套排风罩可安全实施，并考虑同时负荷；

- [ ] 申请主体、CNAE和代表关系已确认；
