# Restaurant Sol el Clot — 获批后执行与补助证明清单

> 内部工作文件。具体期限以正式批准通知和官方电子系统显示为准。不要把本清单当作最终申报文件上传。

## 1. 获批通知后立即确认

- [ ] 保存批准通知的完整 PDF、通知日期和 expediente 编号。
- [ ] 检查是否需要在提案通知后 10 个工作日内明确接受；如需接受，保存提交回执。
- [ ] 记录批准金额、批准的预算类别和允许执行期限。
- [ ] 记录最终执行截止日。
- [ ] 如批准通知与申请预算、设备型号或金额有差异，先核对是否需要接受、澄清或更正。
- [ ] 在实际下单前确认供应商最终发票必须由申请主体取得，且设备型号与获批方案一致。
- [ ] 如需更换设备、调整预算类别或改变实施内容，先判断是否需要正式申请修改；涉及修改时，应至少在执行期限结束前 15 个自然日提交。

## 2. 采购和安装文件

### 设备

- [ ] RATIONAL iCombi Pro 6-1/1 E 的正式发票。
- [ ] 发票上写明品牌、准确型号/参考号 `CB1ERRA.0000817`、数量、净额、IVA和含税总额。
- [ ] RATIONAL底座/支撑架的正式发票分项。
- [ ] 如烤箱和底座在同一张发票上，要求分项列明。
- [ ] 保存送货单、序列号照片和设备铭牌照片。

### 安装

- [ ] 电线、保护装置、已有水电排水点的接驳、UltraVent Plus及直接安装人工分别列明；不自动保留原 2,500 € 排水工程。
- [ ] 如安装了 UltraVent Plus，保存其准确型号、序列号、技术资料、排水/虹吸连接和过滤维护资料。
- [ ] 每个安装项目都能说明其为安装新烤箱所必需。
- [ ] 保存安装方或电工的发票、安装完成证明和必要的电气文件/ boletín。
- [ ] 保存安装前后照片：旧烤箱、拆除过程、新烤箱、底座、独立电线、进水和排水。
- [ ] 原报价中的 2,500 € 不能直接作为执行金额；如供应商改为新报价，保存取消/替代说明和新的实际开票方。

## 3. 付款证明

- [ ] 所有付款均由申请主体账户支付。
- [ ] 保存银行转账凭证、付款日期、收款方、金额和对应发票号。
- [ ] 分期付款时保存每一笔付款及其与发票的对应关系。
- [ ] 不使用无法证明付款主体或无法对应发票的现金付款作为主要证明。
- [ ] 保存供应商发票、付款凭证和送货/安装证明的同名文件夹副本。

## 4. 节能证明

- [ ] 新 RATIONAL 官方技术资料和铭牌照片。
- [ ] 正确旧烤箱的铭牌照片、整机照片和可取得的技术资料。
- [ ] 工业设备技术人员出具的节能比较报告。
- [ ] 报告由与供应商、安装商无关的注册工业技术工程师出具，并保存其独立性/执业证明。
- [ ] 报告至少解释：设备用途、容量、实际运行方式、预热/烹饪时间、控制与保温、旧新设备比较方法和结论。
- [ ] 如果新设备没有适用的能源标签，使用技术报告证明节能，不自行写未经证明的节能百分比。
- [ ] 说明 RATIONAL 对大燃气铁板属于烹饪功能上的替代；本次补助不支付新燃气铁板，也不把燃气节省额写成未经测量的固定金额。若旧铁板保留作工作台，明确说明其未被物理拆除。

## 5. 旧设备和废弃物

- [ ] 保存旧烤箱已拆除的照片和铭牌照片。
- [ ] 将旧烤箱交给授权回收商、干净点或其他合资格接收方。
- [ ] 取得带日期、设备描述和接收方信息的回收/废弃物管理证明。
- [ ] 确保证明能够对应本次被替换的旧烤箱，而不是其他设备。
- [ ] 若申请材料将大燃气铁板作为“正式被替换的旧设备”主张，必须实际拆除并取得该铁板的授权回收证明；若它保留作工作台，只记录其停止烹饪使用，不提交其废弃证明，也不写成已完成正式替换。

## 6. 最终证明包

- [ ] 最终技术/活动说明，描述实际安装完成情况。
- [ ] 设备发票和安装发票。
- [ ] 全部付款凭证。
- [ ] 节能技术报告或适用的能源标签证明。
- [ ] 旧设备回收证明。
- [ ] 活动完成声明/责任声明。
- [ ] 如聘请专业人员准备证明，保存独立服务发票及其付款凭证。
- [ ] 如聘请 gestoría/专业人员，核对申请管理费不超过相关替换成本的 4%，结算管理费不超过相关替换成本的 7%，并分别保存服务发票和付款证明。
- [ ] 按官方系统要求上传，每个文件控制在当前页面规定的大小以内；必要时合并前先确认可读性。
- [ ] 保存最终提交 PDF、Registro 回执、日期时间、注册号和完整上传清单。
- [ ] 按官方公共资金标识要求，在规定期间和公众可见位置展示政府/主管部门标识或其他资助公示材料，并保存照片和实施日期证据。

## 7. 当前官方时间提示

官方《Guía del solicitante》版本 1.0（更新日期 03/08/2026）说明：通常应在批准通知后一个月内执行并支付；执行完成后 15 个自然日内提交证明。若 actuación 在法规生效前已经完成，则期限按批准通知计算。以正式批准通知和后续官方要求为准。

官方指南还说明：如果申请时节能技术报告尚未准备好，可以在补助证明阶段提交。因此，报告可以暂不阻止当前申请准备，但不能在最终证明阶段缺失。
